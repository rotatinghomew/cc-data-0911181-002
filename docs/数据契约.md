# 数据与业务契约

population_low/high 是同一人口组人数的调查区间，不能当不同人群相加。routes 的分钟区间包含步行和公交；maximum_minutes 是该组按 mobility（limited/ordinary）区分的可接受出行上限，不同行动条件不能套用同一上限。偏好权重仅是调查信息，不承诺报名。offers 为现状，proposals 尚未生效。

## 数据集合

- `groups`：主键为 `group`；必填字段 `group, village, population, population_low, population_high, mobility, maximum_minutes, slots`，当前 12 条。
- `offers`：主键为 `offer`；必填字段 `offer, site, topic, slot, seats`，当前 6 条。
- `routes`：主键为 `group + site`；必填字段 `group, site, minutes, minutes_low, minutes_high`，当前 48 条。
- `preferences`：主键为 `group + topic`；必填字段 `group, topic, weight`，当前 36 条。
- `proposals`：主键为 `proposal`；必填字段 `proposal, site, topic, slot, seats`，当前 2 条。

集合中的主键不得重复；schema 的 foreign 引用须指向已存在的记录。可空字段保留 null 的业务含义，不自动补零。

## 查询与材料

GET 查询使用 UTF-8 JSON，错误参数返回 400，不存在的接口返回 404。重复的单值参数视为无效。summary 与 HTTP 调用同一组只读计算，材料包含数据内容指纹和生成时间，便于核对输入。

### 可及性分析接口

- `/api/accessibility`：单情景测算。参数 `proposals`（逗号分隔，缺省为现状）、`travel=low|base|high`、`population=low|base|high`。资格同时判定出行上限、可参加时段与课程；共享余位通过居民组—课程二部网络的最小费用最大流测算，输出“可服务人数能力边界”，不是确定的报名分配。返回各组人口/已服务/未服务、四类未服务原因（`no_reachable_site`、`no_course_nearby`、`no_time_slot_match`、`capacity_constrained`，全部可服务为 `fully_served`）、村级与 mobility 分组服务率及差距、课程占用与余位、偏好权重达成口径（`preference_*`）。
- `/api/proposal-comparison`：现状、每个方案单独、全部方案合并共四类情景，在 travel×population 的 3×3 区间格点上比较。返回逐格排名与 `robust_in_all_cells`（排序是否随合理取值翻转）、两两情景在 9 个格点上的服务量差值与地区差距改善、组级新增服务及低/高区间、只换地方不新增的 `substitution` 明细、以及重叠覆盖的重复计数口径 `overlap`。同一居民组被多个点覆盖只计一次。
- `/api/comparison-basis?basis=编号`：按编号取回已落库的比较依据，供拨付核对。

## 扩点办理协作

业务操作以 JSON 对象 POST 到 `/api/workflow/操作名`，每个操作在本地业务日志的事务中更新；失败不提交半条办理记录。

1. `planning.compare`：按拟投范围（缺省为全部方案）生成比较依据并落库，返回确定性编号 `basis`。依据内含数据指纹、方案范围、受影响人群与新增服务区间。
2. `planning.nominate`：提名必须引用已存在的比较依据；方案超出依据范围、数据指纹与当前数据不一致、资源座位不足或提名编号重复均拒绝。提名快照保存依据指纹、范围与证据（受影响组、换地方组、新增服务区间）。提名不占资源。
3. `funding.approve`：审批时重新校验依据指纹与范围；数据或拟投范围变化导致旧依据失效时阻止沿用。无任一情景区间的新增服务或地区改善证据时拒绝；与已批补助的受影响居民组重叠（同一批人重复受益）时拒绝；金额仍受单场上限与总预算约束。补助记录留存受影响人群明细，可追到具体居民组。
4. `resources.activate`：仅可激活已批提名；资源被其他获批方案启用后不得重复占用（多方案可共享同一处资源，但测算与拨付都不先占）；激活记录的方案与资源必须与拨付对象一致，承诺与拨付对齐。

接口传入业务标识，未知标识或不满足条件返回错误，不自动补建对象。状态库只保留本机操作，不向外部发送数据。
